# Web API (Phase 19) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a FastAPI adapter (`/api/v1`) over the existing session/application layer — game session creation, observation, status, events, actions, and human input — with DTOs distinct from domain objects and idempotency keys on state-changing routes.

**Architecture:** The API is an interface adapter, exactly like the CLI (`CLAUDE.md` §40, §63). Routes construct commands and call the same composition root (`session.factory.build_session`, `session.play.apply_input`) and application services (`GameService`, `GmDirector`) the CLI uses — no duplicate game logic. A per-process `SessionRegistry` maps `game_id → GameSession` (matching the per-process in-memory combat state that already exists); a per-route idempotency cache dedups `POST`s. All expected domain/application/AI errors map to HTTP via exception handlers. Phase 19 is single-process; no background turn loop.

**Tech Stack:** FastAPI + pydantic v2 (new dependency), uvicorn (extras), httpx + Starlette `TestClient` for tests (httpx already a dependency). No new deps beyond those.

**Spec:** `docs/architecture/domain-model-and-api.md` (written by the plan `2026-09-13-domain-model-api-contract.md`) — the plan argues from the contract; executors read both. §22 of `docs/Agentic Conclave-Implementation Plan.md` fixes the route set.

**Roadmap:** `docs/superpowers/plans/README.md` row #10 (Phase 19).

## Global Constraints

- **Interface layer only**: all new source lives under `src/interfaces/api/`. `src/domain` and `src/application` are untouched except where a genuine port extension is required (none anticipated): verify `git diff --stat master..HEAD -- src/domain src/application` is empty in the final task.
- **No game logic in routes**: handlers validate input, build commands, call services/session helpers, map results to DTOs (`CLAUDE.md` §40).
- **DTO separation** (`§41`): pydantic request/response models in `src/interfaces/api/dto.py` mirror application views; domain objects never cross the wire directly.
- **No secrets**: provider keys come from env (`OPENCODE_API_KEY`/`OPENROUTER_API_KEY`/`DATABASE_URL`) via the existing `session.factory` resolution. Never log or echo them.
- **Deterministic tests**: default test config uses `agent_mode="fake"`, `gm_mode="off"` (`SessionConfig` already supports both). No live LLM calls; the offline suite runs without API keys.
- **Single-process** (contract §6): combat/dice/message-board state is per-process; document `uvicorn --workers 1` in the run instructions. Per-game `threading.Lock` serializes mutations within the process.
- **Type/lint gates**: `ruff check .` clean (line 100, E/F/I/UP/B); `mypy --strict` clean on `src` (FastAPI + pydantic app code included).

```python
"""HTTP DTOs: pydantic models mirroring application views field-for-field.

Contract: docs/architecture/domain-model-and-api.md §1.
"""
from pydantic import BaseModel

from application.gm.director import GmResult
from application.views import GameView, TurnReport
from domain.events.collector import EventEnvelope  # adjust to the module found by grep


class CharacterResponse(BaseModel):
    id: str
    name: str
    character_class: str | None
    level: int
    hp_current: int
    hp_max: int
    armor_class: int
    conditions: list[str]
    is_defeated: bool


class InitiativeEntryResponse(BaseModel):
    character_id: str
    name: str
    total: int


class CombatResponse(BaseModel):
    round_number: int
    status: str
    active_actor_id: str | None
    initiative_order: list[InitiativeEntryResponse]


class GameViewResponse(BaseModel):
    game_id: str
    campaign_name: str
    status: str
    party: list[CharacterResponse]
    enemies: list[CharacterResponse]
    combat: CombatResponse | None


class EventEnvelopeResponse(BaseModel):
    sequence: int
    event_id: str
    game_id: str
    occurred_at: str
    event_type: str
    payload: dict[str, object]


class TurnReportResponse(BaseModel):
    game_id: str
    accepted: bool
    error_code: str
    reason: str
    events: list[EventEnvelopeResponse]
    view: GameViewResponse
    game_over: bool


class StatusResponse(BaseModel):
    status: str
    combat: CombatResponse | None
    game_over: bool


class GmResponse(BaseModel):
    narration: str
    npc_reply: str | None
    addressed_to: str | None


def game_view_response(view: GameView) -> GameViewResponse:
    return GameViewResponse.model_validate(view, from_attributes=True)


def event_response(envelope: EventEnvelope) -> EventEnvelopeResponse:
    return EventEnvelopeResponse(
        sequence=envelope.sequence,
        event_id=str(envelope.event_id),
        game_id=str(envelope.game_id),
        occurred_at=envelope.occurred_at,
        event_type=envelope.event_type,
        payload=dict(envelope.payload),
    )


def turn_report_response(report: TurnReport) -> TurnReportResponse:
    return TurnReportResponse(
        game_id=report.game_id,
        accepted=report.accepted,
        error_code=report.error_code,
        reason=report.reason,
        events=[event_response(event) for event in report.events],
        view=game_view_response(report.view),
        game_over=report.game_over,
    )


def status_response(view: GameView) -> StatusResponse:
    if view.combat is not None and view.combat.status == "ENDED":
        return StatusResponse(status=view.status, combat=None, game_over=True)
    return StatusResponse(
        status=view.status,
        combat=view.combat,
        game_over=view.status == "ENDED",
    )


def gm_response(result: GmResult | None) -> GmResponse | None:
    if result is None:
        return None
    return GmResponse(
        narration=result.narration,
        npc_reply=result.npc_reply,
        addressed_to=result.addressed_to,
    )
```

Full file content:

```python
"""Per-process session registry and idempotency cache for the web API."""
import threading


class SessionRegistry:
    """Maps game_id → GameSession for this API process."""

    def __init__(self, *, agent_mode: str, gm_mode: str) -> None:
        self._agent_mode = agent_mode
        self._gm_mode = gm_mode
        self._sessions: dict[str, GameSession] = {}
        self._locks: dict[str, threading.Lock] = {}
        self._global_lock = threading.Lock()

    def build(self, config: SessionConfig) -> str:
        session = build_session(config)
        game_id = str(session.game_id)
        with self._global_lock:
            self._sessions[game_id] = session
            self._locks[game_id] = threading.Lock()
        return game_id

    def get(self, game_id: str) -> GameSession:
        try:
            return self._sessions[game_id]
        except KeyError:
            raise KeyError(game_id) from None

    def __contains__(self, game_id: object) -> bool:
        return game_id in self._sessions

    def lock_for(self, game_id: str) -> threading.Lock:
        return self._locks.get(game_id, threading.Lock())


class IdempotencyStore:
    """In-process dedup for state-changing routes, scoped by route."""

    def __init__(self) -> None:
        self._responses: dict[tuple[str, str], object] = {}

    def response_or(self, key: str, scope: str) -> object | None:
        return self._responses.get((key, scope))

    def remember(self, key: str, scope: str, response: object) -> None:
        if key:
            self._responses[(key, scope)] = response
```

```python
from typing import Callable

from fastapi import Request
from fastapi.responses import JSONResponse
from pydantic import BaseModel

SCOPE_CREATE_GAMES = "POST /games"


def _idempotent(
    request: Request,
    scope: str,
    success_status: int,
    build: Callable[[], BaseModel],
) -> Response:
    key = request.headers.get("Idempotency-Key", "")
    cached = idempotency.response_or(key, scope)
    if cached is not None:
        return JSONResponse(cached, status_code=success_status)
    body = build()
    idempotency.remember(key, scope, body.model_dump())
    return JSONResponse(body.model_dump(), status_code=success_status)
```

Restructure the `/games` handler around it (first call computes; replay returns the cached payload with the same status):

```python
@app.post("/api/v1/games")
```

```python
@app.post("/api/v1/games/{game_id}/actions")

    session = registry.get(game_id)

        view = session.game_service.get_view(game_id)
        actor_id = _active_actor(view)
        target = _matching_character(view, action_request.target) if action_request.target else None

        command = SubmitActionCommand(

            weapon_id=action_request.weapon_id,
```

```python
from ai.models.errors import ModelError
from application.gm.director import InvalidGmResponseError
from domain.common.errors import (
    ActionNotAvailableError,
    AgentDecisionFailedError,
    CharacterNotFoundError,
    CombatNotActiveError,
    ConcurrentGameModification,
    GameNotFoundError,
    GameNotRunningError,
    InsufficientResourceError,
    InvalidActionError,
    NotYourTurnError,
    PersistenceError,
    ValidationError,
)

HANDLER_TABLE: dict[type[Exception], tuple[int, str]] = {
    GameNotFoundError: (404, "game_not_found"),
    CharacterNotFoundError: (404, "character_not_found"),
    ValidationError: (422, "validation_error"),
    InvalidActionError: (422, "invalid_action"),
    InsufficientResourceError: (422, "insufficient_resource"),
    NotYourTurnError: (409, "not_your_turn"),
    ActionNotAvailableError: (409, "action_not_available"),
    CombatNotActiveError: (409, "combat_not_active"),
    GameNotRunningError: (409, "game_not_running"),
    AgentDecisionFailedError: (502, "agent_decision_failed"),
    ConcurrentGameModification: (409, "concurrent_modification"),
    PersistenceError: (503, "persistence_error"),
    ModelError: (502, "model_error"),
    InvalidGmResponseError: (502, "gm_invalid_response"),
}


def register_error_handlers(app: FastAPI) -> None:
    def handler(status: int, code: str):
        def handle(request: Request, exc: Exception) -> JSONResponse:
            return JSONResponse(
                status_code=status,
                content={"error": code, "reason": str(exc)},
            )

        return handle

    for exc_type, (status, code) in HANDLER_TABLE.items():
        app.add_exception_handler(exc_type, handler(status, code))

    @app.exception_handler(DomainError)
    def unlisted_domain_error(request: Request, exc: DomainError) -> JSONResponse:
        return JSONResponse(
            status_code=409,
            content={"error": "domain_error", "reason": str(exc)},
        )

    @app.exception_handler(Exception)
    def internal(request: Request, exc: Exception) -> JSONResponse:
        return JSONResponse(
            status_code=500,
            content={"error": "internal_error", "reason": "internal server error"},
        )
```

(The `DomainError` fallback covers any unlisted subclass — exact classes match first because Starlette walks the exception's MRO and prefers the most specific registered handler. `KeyError`/`AgentNotRegisteredError` are deliberately unmapped: a bare-`KeyError` handler would mask real bugs, and no Phase 19 route raises it.)

```python
def submit_input(game_id: str, request: InputRequest, http_request: Request) -> Response:
    session = registry.get(game_id)
    with registry.lock_for(game_id):
```
